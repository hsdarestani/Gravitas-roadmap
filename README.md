# Gravitas Roadmap

An interactive, slide-by-slide roadmap document for Gravitas.

The current presentation interface is Persian. The roadmap now defines English as the primary language of Gravitas content, with additional localized editions added according to audience, topic, and production capacity.

## Cloudflare Pages

- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `.`
- Root directory: leave empty
- Production branch: `main`

The site is static and has no build dependency.

## Comments

The document includes an Utterances-powered comments drawer. Comments are stored as GitHub Issues in this repository.

One repository-owner action is required before the embedded widget can publish comments:

1. Install the **Utterances GitHub App** for `hsdarestani/Gravitas-roadmap`.
2. Keep GitHub Issues enabled for the repository.

A direct GitHub feedback link is included in the interface as a fallback.

## Controls

- Mouse wheel and vertical swipe
- Arrow keys, Page Up / Page Down, Home / End
- Previous and next controls
- Chapter rail and structured table of contents
- Comments drawer
- Print button for PDF export
