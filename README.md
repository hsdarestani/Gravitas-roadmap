# Gravitas Roadmap

An interactive, slide-by-slide Persian roadmap for Gravitas.

## Cloudflare Pages

- Framework preset: `None`
- Build command: leave empty
- Build output directory: `/`
- Root directory: `/`

The site is fully static and has no external library or build dependency.

## Controls

- Mouse wheel / vertical swipe
- Arrow keys, Page Up / Page Down, Home / End
- On-page previous / next controls
- Table of contents
- Print button for PDF export
